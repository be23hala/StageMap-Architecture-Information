# StageMap — Projet d’Architecture de l’Information

## Présentation
StageMap est un mini-site statique qui présente la conception de l’architecture de l’information
d’un portail de recherche et d’orientation vers les stages.

Le projet couvre :
- Sitemap
- User flows / flowcharts
- Wireframes orientés IA
- Métadonnées
- Vocabulaire contrôlé
- Ontologie
- Modélisation et structuration de contenu

## Structure des fichiers


## Mise en ligne avec GitHub Pages
1. Créer un dépôt GitHub.
2. Ajouter tous les fichiers du projet.
3. Aller dans **Settings > Pages**.
4. Choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/root`.
6. Enregistrer puis ouvrir le site publié.
