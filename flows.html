Accueil / User flows

Parcours utilisateurs et flowcharts

Les user flows décrivent les étapes suivies par un utilisateur pour atteindre un objectif. Ici, trois scénarios clés ont été retenus pour représenter les usages majeurs du portail.

Recherche d’offre Préparation de candidature Exploration d’entreprise

Flow 1 — Trouver une offre de stage adaptée

Objectif : permettre à un étudiant d’identifier une offre pertinente en quelques étapes.

1. AccueilEntrée dans le portail.
→
2. OffresOuverture de la liste.
→
3. FiltresDomaine, ville, durée.
→
4. RésultatsComparaison des offres.
→
5. DétailLecture complète de l’offre.
Décision de conception : les filtres apparaissent avant les résultats afin de soutenir une recherche ciblée et de limiter la surcharge cognitive.

Flow 2 — Préparer sa candidature

Objectif : guider l’utilisateur depuis un besoin flou jusqu’à une ressource concrète.

1. AccueilRepérage de la rubrique Conseils.
→
2. ConseilsChoix d’un thème.
→
3. CVLecture du guide.
→
4. RessourceAccès à une checklist.
Décision de conception : les ressources pratiques sont reliées aux contenus-conseils pour favoriser la continuité entre apprentissage et action.

Flow 3 — Explorer une entreprise

Objectif : comprendre une organisation et les stages qu’elle propose.

1. AccueilAccès à la section Entreprises.
→
2. SecteurSélection d’un domaine.
→
3. FicheConsultation de l’entreprise.
→
4. Stages liésVoir les opportunités.
